Ten ways the workflow could look

Redesign concepts for the Stones Throw Studio order workflow. Every one renders the same real data — the same 16 orders, the same eight pipeline stages, the same dashboard widgets — so the only thing changing between them is the design. Each has its own light and dark mode.

How to use this: the toggle above flips all ten previews at once — worth doing, because several designs are far more convincing in one mode than the other. Click any tile to open it full-screen, where you can switch between the Dashboard and the Order Pipeline and use that design's own theme toggle. Nothing here touches the live app.
01 Atelier Open ↗

The current blue-and-gold identity, done properly — serif headings, real whitespace, calmer elevation.
02 Workbench Open ↗

Information-dense and utilitarian. Minimal chrome, tabular numbers, far more orders visible per screen.
03 Editorial Open ↗

Laid out like a magazine. Large serif display type, generous margins, muted paper stock, one vermilion accent.
04 Glass Open ↗

Glassmorphic. Translucent layered surfaces over a live gradient field, backdrop blur, luminous accents.
05 Brutalist Open ↗

Zero radius, heavy rules, hard offset shadows, monospace labels, unmixed primaries. Loud and unmistakable.
06 Terminal Open ↗

Monospace throughout, command-bar driven, phosphor accent. Dark-native and keyboard-forward.
07 Warm Craft Open ↗

The bench itself — kraft paper and linen texture, warm neutrals, gold-foil accents, hand-drawn edges.
08 Soft Open ↗

Neumorphic calm. Low contrast, extruded surfaces, generous radius — nothing shouts at you.
09 Product Open ↗

Modern SaaS discipline — hairline borders, tight neutral greys, small confident type. Dark-first.
10 Bento Open ↗

The dashboard as a mosaic. Mixed-size tiles, per-tile colour identity, playful proportion, fast to scan.
